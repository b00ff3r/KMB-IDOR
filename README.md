# CTF Notes — уязвимость IDOR

Простое Flask-приложение с намеренно оставленной уязвимостью **IDOR (Insecure Direct Object Reference)**.  
Задача для участников CTF: получить скрытую заметку с ID `1`, которая содержит флаг.

## 📌 Функционал
- Регистрация и вход пользователей (данные хранятся в памяти).
- После входа отображается дашборд с 4 случайными заметками.
- Каждая заметка открывается на отдельной странице `/notes/<id>`.
- **Уязвимость**: отсутствует проверка владельца заметки → можно открыть `/notes/1` и увидеть флаг.
